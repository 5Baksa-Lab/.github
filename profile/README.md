# 🧠 5박사 연구소 (5Baksa-Lab)

**AI Research & Development Organization**

Computer Vision (CV) · Generative AI · AI-driven Digital Experiences

---

## 🚀 About

**5박사 연구소**는 **Computer Vision과 Generative AI를 결합하여
사람들이 안전하고 자유롭게 자신을 표현할 수 있는 디지털 경험을 만드는 AI 연구·개발 조직입니다.**

우리는 빠르게 실험 가능한 **MVP를 개발하고**,
사용자 데이터와 피드백을 기반으로 서비스를 **지속적으로 개선하는 실험 중심 개발 방식**을 지향합니다.

---

## 🧩 Active Project

### 🐾 Pokéman — CV 기반 아바타 익명 힐링 SNS (MVP)

사용자 사진 1장을 기반으로 얼굴 특징을 추출하고
이를 긍정적으로 재해석한 **오리지널 크리처(아바타)**로 변환하여
**익명 기반 힐링 소통 경험**을 제공하는 서비스입니다.

---

### ✨ Key Features

🧬 **AI Avatar Generation**

* 얼굴 특징 추출 (Computer Vision)
* 특징 → 크리처 속성 매핑
* 이미지 생성 (Generative AI)
* 스토리 / 이름 자동 생성 (LLM)

📖 **Storybook Experience**

* Ken Burns 스타일 이미지 연출
* Typewriter 애니메이션 텍스트
* 감정 연출을 위한 BGM 토글

🌐 **Social Sharing**

* 카카오 / 인스타 / X 공유
* URL 공유 기능

🌟 **Creature Gallery (포켓 도감 광장)**

* 익명 기반 크리처 피드
* 고정 이모지 리액션
* 댓글 없는 가벼운 소통 구조

## 🧑‍💻 Getting Started

### 1️⃣ Local Development

1. 각 repository clone
2. `.env.example` → `.env` 설정
3. Docker 기반 서비스 실행

### 2️⃣ MVP Pipeline

1. 이미지 업로드
2. 얼굴 검출 및 특징 추출
3. 특징 → 크리처 속성 매핑
4. 이미지 생성 + 스토리 생성
5. 결과 저장 및 공유 링크 생성
6. (옵션) 광장 게시 및 리액션
